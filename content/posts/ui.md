# UI

`@homecode/ui` is a React design system for keeping interfaces consistent across products and avoiding repeated UI work. It provides:

- Common controls, forms, navigation, and layouts
- Overlays, data display, media, and formatted content
- Themes, icons, and larger screen-level building blocks

## Use it

The components include TypeScript support and work in browser-rendered and server-rendered projects. The documentation presents live examples, while the package and source are available for reuse.

- [Browse the documentation](https://ui.apostol.space)
- [Install the package](https://www.npmjs.com/package/@homecode/ui)
- [View the source](https://github.com/foreverido/uilib)
