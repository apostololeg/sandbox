# SVG Dot Work

SVG Dot Work is a small browser tool for creating dotted vector artwork. Start with the included world map or upload an image to use as the shape.

## Create and export

- Adjust dot density, size, and color
- Preview changes immediately
- Optimize and download the result as SVG

No account is required.

[Create dotted SVG artwork](https://svg-dot-work.apostol.space).
